# 00_methodology_and_data_audit

## Purpose

This folder stores manuscript-facing methodology and data-audit documentation. It should summarize final methods clearly, without requiring the reader to inspect every intermediate file in `Data/testing_clean`.

## Current Methodology Documents

| File | Content |
|---|---|
| `01_data_cleaning_methods_detailed_ZH.md` | Detailed data-cleaning workflow from raw W2/W3 files to final W2 ver6 and W3 ver5 datasets. |
| `02_data_cleaning_source_index_ZH.md` | Source index explaining which `Data/testing_clean` files are final evidence, audit evidence, or intermediate versions. |
| `03_feature_decomposition_methods_ZH.md` | Manuscript-facing feature-decomposition methodology, including subscale definitions, scoring rules, reliability checks, and drop-only vs decomposition performance evidence. |
| `04_feature_inventory_ZH.md` | Inventory of planned/current main-paper features with question IDs, Chinese names, English names, and usage notes. |

## Supporting Files

| Folder | Content |
|---|---|
| `feature_decomposition_supporting_files/` | Minimal supporting files copied from `Feature_Decomposition`: subscale definition table, decomposition performance summary, and reliability workbooks. |
| `feature_inventory_supporting_files/` | Full feature inventory workbook and CSV for main-paper predictors, outcomes, moderators, and interpersonal features. |
