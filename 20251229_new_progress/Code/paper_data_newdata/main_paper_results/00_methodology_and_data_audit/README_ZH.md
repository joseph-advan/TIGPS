# 00_methodology_and_data_audit

## 目的

這個資料夾用來放論文 Methods 可以直接參考的方法論與資料清理紀錄。它的目的不是保存所有中間檔，而是把最終會用到的清理流程整理成清楚、可引用、可解釋的文件。

## 目前文件

| 檔案 | 內容 |
|---|---|
| `01_data_cleaning_methods_detailed_ZH.md` | 從原始 W2/W3 到最終 W2 ver6 / W3 ver5 的完整 data cleaning 流程。 |
| `02_data_cleaning_source_index_ZH.md` | 說明 `Data/testing_clean` 裡哪些檔案是主要證據、哪些是 audit evidence、哪些只是中間版本。 |
| `03_feature_decomposition_methods_ZH.md` | 論文可直接參考的 feature decomposition 方法文件，包含拆題組邏輯、小題組定義、計分規則、Cronbach's alpha 與模型表現檢查。 |
| `04_feature_inventory_ZH.md` | 主論文預計/目前使用特徵清單，包含題號、中文名稱、英文名稱與使用位置。 |
