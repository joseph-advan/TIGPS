# GraphSAGE GNN Performance

This wrapper reruns the existing GraphSAGE three-task script and copies the W2 -> W2 and W2 -> W3 outputs into this model-performance folder.

Version rule: GraphSAGE is run only with the current drop + decomposition node features. No no-drop GNN version is run or reported.

GraphSAGE metrics are means over 5 random seeds, not CV5 folds.
