# 08_longitudinal_change_analysis

## Purpose

Longitudinal transition and change analyses, such as W2 features predicting W3 distress or distress change groups.

## What should go here

- Final or manuscript-facing summaries.
- Small source snapshots needed for traceability.
- Explanation files that help connect results to the paper narrative.

## What should not go here

- Large raw intermediate files unless they are the final evidence used in the paper.
- Experimental outputs that are not part of the current story.
- Original scripts if they are already maintained in their source analysis folder.
