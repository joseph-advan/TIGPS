Methodology
    資料清理
        整理 W2 與 W3 學生問卷資料。
        統一 student_id 格式，建立可跨年度對齊的 paired sample。
        針對重複提名、自我提名、無效座號等 peer nomination 資料進行清理。

    Feature Decomposition
        有些題組本身太大，理論上可能包含不同心理構念。
        因此將部分題組拆成 subscales，例如 social media self-presentation、FOMO、SEL competencies。
        每個 subscale 使用題項平均分數。
        多題量表採用至少 50% valid item rule。
        使用 Cronbach's alpha 檢查拆分後題組的內部一致性。
        Feature decomposition 的目的不是只追求模型 AUC，而是提升解釋性與理論對應性。

Interaction Analysis：Online Activity 是否改變保護因子的效果


    Task	Feature	b1	b2	b3	b3 p-value
    W2 -> W3	Family Cohesion and Support (Family Functioning)	-0.2947	0.2250	-0.1117	0.036
    代入模型：

    logit(P(High Psychological Distress = 1))
    = 0.3002
      + (-0.2947) * Family Cohesion
      + 0.2250 * High Online Activity
      + (-0.1117) * Family Cohesion * High Online Activity
      + covariates
    Low Online Activity：

    intercept = b0 = 0.3002
    slope = b1 = -0.2947
    OR = exp(-0.2947) = 0.745
    High Online Activity：

    intercept = b0 + b2 = 0.3002 + 0.2250 = 0.5252
    slope = b1 + b3 = -0.2947 + (-0.1117) = -0.4063
    OR = exp(-0.4063) = 0.666
    Interaction：

    b3 = -0.1117
    p = 0.036
    interaction OR = exp(-0.1117) = 0.894


家庭凝聚與支持在低線上活動與高線上活動學生中都呈現保護效果，但此保護效果在高線上活動學生中更強。這表示對線上活動較高的學生而言，較高的家庭支持可能更能降低其未來高心理困擾風險。



整體結論：
    本研究首先比較 Logistic、LASSO、Ridge 與 GraphSAGE 在橫斷面（W2 -> W2）與縱貫面（W2 -> W3）的心理困擾預測表現。
    結果顯示，GraphSAGE 並未優於非 GNN 模型，表明現有同儕提名網絡的圖結構資訊未提供顯著的額外預測效益。
    同時，縱貫分析與 LASSO 特徵選擇亦指出，同儕網絡特徵的增量貢獻有限，青少年的心理狀態更高度依賴於個體的社會情緒能力（SEL / Resilience）、數位生活型態、學校歸屬與家庭支持。

    進一步的交互作用分析揭示了一項關鍵的「數位時代保護機制」。
    在數位世代的脈絡下，高度線上活動常伴隨資訊焦慮與人際比較等潛在壓力；然而，「家庭凝聚與支持（Family Cohesion and Support）」對未來高心理困擾的保護效果，在高度投入線上活動的群體中被顯著放大。

    整體而言，本研究證實，面對數位生活帶來的心理健康挑戰，穩固的家庭與學校實體脈絡及個人情緒韌性，仍是比同儕網絡結構更核心的防護網。
